## 🔌 Реалізовані алгоритми

### 🗜️ Алгоритм Хаффмана

Використовується для усунення кодової надлишковості шляхом побудови дерева кодування на основі частоти появи символів.

### 🗜️ RLE (Run-Length Encoding)

Використовується для стискання послідовностей однакових значень шляхом збереження значення та кількості його повторень.

### 🔄 Різницеве перетворення

Використовується для усунення міжелементної надлишковості шляхом заміни значень пікселів різницями між сусідніми елементами.

## 📊 Результати дослідження

У роботі було проведено дослідження ефективності методів стискання для:

- фотографічних зображень;
- текстурних зображень;
- бінарних зображень;
- шумових зображень.

Отримані результати показали, що найбільший коефіцієнт стискання досягається для бінарних зображень, тоді як шумові зображення демонструють найменшу ефективність стискання через високий рівень ентропії.
